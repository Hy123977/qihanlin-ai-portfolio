医院行政 AI 文档处理中心

针对医院行政文书“耗时长、错误率高、档案检索慢”，且医疗数据不能外泄的痛点，独立设计并开发“批量导入 → 智能识别 → 要素提取 → 分类归档 → 安全审查”四阶段处理流水线，结果以结构化提取、AI 生成文书、分级质控报告三 Tab 呈现；PDF / Word / 图片全部在浏览器本地解析（PDF.js、Tesseract、Mammoth），内容不出端。6 份文档处理约 13 秒；数据库启用行级安全策略与审计列。当前 AI 结果为预置数据与规则模拟，不调用外部模型 API，效率指标按演示口径呈现。

工作流编排React + NestJS本地 OCRRLS 安全
在线体验

税务师备考助手

针对税务师备考资料分散、缺少统一进度入口的问题，独立设计并开发单页备考工作台，整合课程、名师、阶段规划、科目、资源与考试倒计时六大模块，内置学习倒计时、数据图表、资源一键复制与随机鼓励交互。共整合 22 门课程、22 位名师、5 大科目与 20 项资源，倒计时锚定 2027-11-13 考试；基于 React 19 + TypeScript + Vite + TailwindCSS + ECharts 实现，纯前端、零后端，可直接托管分享。
